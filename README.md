# StudyPDF Library

A modern, clean website interface for managing your personal study PDF library. Upload, categorize, and search through your PDFs with an intuitive and responsive design.

## Features

- 📚 **PDF Upload**: Drag & drop or click to upload PDF files
- 🏷️ **Categorization**: Organize PDFs into Academic, Research, Notes, and Books categories
- 🔍 **Search**: Find PDFs by title, description, or category
- 📱 **Responsive Design**: Works perfectly on desktop and mobile devices
- 👁️ **Preview**: View PDFs directly in the browser
- 💾 **Local Storage**: All data is stored locally in your browser
- 🎨 **Modern UI**: Bright, friendly color scheme with smooth animations

## Getting Started

1. Open `index.html` in your web browser
2. Start uploading your PDFs using the "Upload PDF" button
3. Organize them with categories and descriptions
4. Use the search bar and filter tabs to find what you need

## How to Use

### Uploading PDFs
1. Click the "Upload PDF" button
2. Drag and drop a PDF file or click to browse
3. Fill in the title, select a category, and add an optional description
4. Click "Upload" to add it to your library

### Organizing PDFs
- Use the filter tabs to view PDFs by category:
  - **All**: Shows all PDFs
  - **Academic**: Course materials and educational content
  - **Research**: Research papers and studies
  - **Notes**: Personal notes and summaries
  - **Books**: Books and comprehensive materials

### Searching
- Use the search bar to find PDFs by:
  - Title
  - Description
  - Category

### Viewing PDFs
- Click on any PDF card to preview it
- Use the download button to save the PDF
- Use the delete button to remove PDFs from your library

## Technical Details
